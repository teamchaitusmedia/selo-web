Selo privacy policy

Last updated 19 October 2026 · Selo

Selo is a photo file manager made by Chaitus Media for its own studio staff. This page says what Selo does with Google account data and with the files it moves between the studio's PCs.

What Selo asks Google for

Selo asks for one permission: to see, create and delete only the Google Drive files that Selo itself made (Google's drive.file permission), plus the email address of the account, to show which account is connected. Selo cannot see, open or change any other file in the Google Drive.

What Selo keeps in Google Drive

  • An address book in a folder named "Selo studio network": one small entry per studio PC, holding the PC's name, the name its user typed into Selo, a connection ID, and when it last checked in. The studio's PCs use it to find each other over the internet.
  • Files sent between studio PCs, only when two PCs cannot connect directly (for example, the receiving PC is switched off). They are deleted as soon as the receiving PC has them, and any left behind are deleted after 14 days.

What Selo does not do

  • It does not send Google data to Chaitus Media's servers or to anyone else. There are no such servers: Selo talks only to Google and to the studio's own PCs.
  • It does not sell, share or use any data for advertising, and it does not use it to train AI models.
  • No person at Chaitus Media reads the address book or the files, except the studio staff the files were sent to.

How it is protected

The Google sign-in is stored only on the studio PC, encrypted for that Windows user. Files and messages between studio PCs travel over encrypted connections. When two PCs cannot reach each other directly, the connection may pass through a public relay server run by the makers of the networking library Selo uses (iroh, by n0). The relay only forwards encrypted traffic and cannot read it.

Removing access

Right-click your name in Selo and choose "Disconnect from studio PCs outside", or remove Selo at myaccount.google.com/permissions. Deleting the "Selo studio network" folder from the Google Drive deletes everything Selo kept there.

Google API Services User Data Policy

Selo's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
